# 06Pressable

Práctica de React Native sobre props y componentes reutilizables. `PressableButton` recibe la prop `texto` y la muestra como contenido del botón. La pantalla principal reutiliza el componente cuatro veces con textos distintos.

## Ejecutar

```bash
npm install
npx expo start
```

Pulsa `w` para abrir la versión web, o usa Expo Go para ejecutar la aplicación en un dispositivo móvil.

## Props

Las props son valores que un componente padre entrega a un componente hijo. Permiten configurar y reutilizar un componente sin duplicar su implementación. En esta práctica, la prop `texto` cambia la etiqueta visible de cada botón.
